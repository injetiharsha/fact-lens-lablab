# Submission Assets

This folder contains submission-oriented content for the hackathon.

## Files

- `SUBMISSION.md`: copy-ready text for form fields (title, short/long description, tags, demo checklist).

## Canonical Project Docs

Use the root README as the source of truth for project explanation:

- `../README.md`

It contains:

- architecture and agent roles

## Suggested Workflow

1. Finalize deployment URL.
2. Fill `SUBMISSION.md`.
3. Capture cover image from `workflow.html`.
4. Record demo video (2-3 minutes).
5. Submit with GitHub repository link and public app URL.
